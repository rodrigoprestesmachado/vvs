# Exercícios de Revisão 📝

Esta página reúne, em um só lugar, os exercícios práticos e teóricos das
disciplinas que caem na Primeira Avaliação. Use-a para revisar antes da prova.
{: .fs-3 }

## Exercícios práticos

* [Maven](https://vvs.rpmhub.dev/maven/maven.html#exercício-): configure o
  PMD e o Checkstyle em um projeto Maven e execute a fase `verify`.
* [PMD e Checkstyle](https://vvs.rpmhub.dev/pmd/pmd.html#exercício-prático-%EF%B8%8F):
  crie um projeto Java/Maven, adicione o PMD e o Checkstyle e configure o
  build para falhar quando houver problemas no código.
* [Teste Unitário (JUnit)](https://vvs.rpmhub.dev/unitario/junit.html#exercícios-práticos-testando-book):
  escreva a classe `BookTest`, cobrindo criação válida, rejeições com
  `assertThrows` e validação de ISBN, a partir do exemplo hexagonal.
{: .fs-3 }
